# Interoviz — High-End Architectural Visualization & Spatial Design Studio

A high-performance, immersive portfolio and interactive web platform for **Interoviz**, specializing in architectural 3D visualization, interior renders, custom furniture joinery, and spatial real-time experiences.

## ✨ Features
- **Cinematic Portfolio Experience:** High-resolution masonry grid showcasing curated Interior, Exterior, Furniture, and Virtual Reality typologies.
- **Real-Time 3D Viewers:** Interactive WebGL/Three.js orbit controls for bespoke 3D assets (`model-viewer` with PBR materials, dynamic shadows, and live rotation).
- **Dual-Tier Category Filtering:** Level 1 primary categories (Interior, Exterior, Furniture, VR, Photography) with contextual subcategories (Hospitality, Residential, Commercial, Overseas).
- **Fullscreen Luxury Lightbox:** High-resolution media lightbox with smooth keyboard arrow navigation and backdrop blur.
- **Smooth Inertial Scrolling:** Powered by Lenis and GSAP ScrollTrigger animations.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
